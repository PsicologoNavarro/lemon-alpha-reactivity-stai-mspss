# v1.0.0 — reproducible analysis release

Initial end-to-end software release for the exploratory analysis of trait anxiety, perceived social support, and posterior alpha reactivity in the public LEMON dataset.

Included:

- official-source metadata/cohort downloader with reference hashes;
- BrainVision source audit and documented recovery/exclusion rules;
- 61-channel EO/EC preprocessing with ICA/ICLabel and frozen QC;
- exact 1–45 Hz, 88-interval and four-canonical-band PSD construction;
- participant-level spline analyses, diagnostics, sensitivities, aggregate tables, and publication figures;
- privacy, syntax, manifest, and release-metadata auditors;
- aggregate reference outputs only.

Not included:

- raw or processed LEMON data;
- participant-level psychometric or EEG measurements;
- the generated 180.47 MiB full-frequency table.

Review the active citation/Zenodo metadata, confirm licensing and release authorization, and pass the release audit before publishing this release.
